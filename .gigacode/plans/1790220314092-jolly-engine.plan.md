# План реализации парсера Ozon

## Архитектура проекта

```
тестовое задание YOURFit/
├── main.py                    # Entry point (запуск модулей)
├── get_cookies.py             # Авторизация + получение cookies
├── parse_ozon.py              # Парсинг карточек товаров
├── gmail_reader.py            # Чтение кода подтверждения из Gmail (IMAP)
├── ozon_parser.py             # Логика парсинга одной карточки товара
├── config.py                  # Конфигурация (email, phone, SKU, paths)
├── requirements.txt           # Зависимости

├── products.csv               # Результат парсинга (gitignored)
└── .gitignore
```

## Технический стек

| Компонент | Решение | Обоснование |
|-----------|---------|-------------|
| Браузерная автоматизация | **Playwright** | Ozon использует ABT (AntiBot Technology) — прямые запросы `requests` получают 403. Playwright headless справляется с JS-challenge |
| Парсинг HTML | **BeautifulSoup4** | Надёжный парсер для извлечения данных из HTML |
| Gmail | **IMAP** (stdlib) | Проще, чем Gmail API (не нужен OAuth2). Требуется App Password |
| Cookies | **JSON-файл** | Простое сохранение/загрузка через `requests.cookies` |
| Выходные данные | **CSV** (stdlib) | Универсальный формат для ETL-пайплайна |
| Логирование | **logging** (stdlib) | Стандартный модуль Python |
| Конфигурация | **config.py + .env** | Чувствительные данные в env-переменных |

## Шаг 2: gmail_reader.py — Чтение кода из Gmail

**Файл:** `gmail_reader.py`

Функция `get_ozon_confirmation_code()`:
1. Подключается к `imap.gmail.com:993` по SSL
2. Авторизуется по email + App Password
3. Ищет письма от `@ozon.ru` с кодом подтверждения (регулярка `\b\d{4,8}\b`)
4. Проверяет subject и body письма
5. Возвращает строку с кодом или `None`
6. Закрывает соединение

Обработка ошибок:
- `imaplib.IMAP4.error` — неверные учётные данные
- Нет найденных писем — лог + возврат `None`
- Таймаут подключения — retry с задержкой

## Шаг 3: get_cookies.py — Авторизация и получение cookies

**Файл:** `get_cookies.py`

### Flow авторизации на data.ozon.ru:

1. **Открытие страницы** через Playwright:
   ```python
   from playwright.sync_api import sync_playwright
   with sync_playwright() as p:
       browser = p.chromium.launch(headless=True)
       context = browser.new_context()
       page = context.new_page()
       page.goto("https://data.ozon.ru/")
   ```

2. **Ввод номера телефона**:
   - Найти поле ввода (по placeholder "Телефон" или input type="tel")
   - Ввести номер из config
   - Нажать "Продолжить" / кнопку отправки кода

3. **Получение кода из Gmail**:
   - Вызвать `gmail_reader.get_ozon_confirmation_code()`
   - Retry-цикл: ждать письмо до 60 секунд, проверка каждые 5 секунд
   - Логировать каждый шаг

4. **Ввод кода подтверждения**:
   - Найти поле ввода кода (обычно 4-8 инпутов)
   - Ввести полученный код
   - Нажать "Войти" / "Подтвердить"

5. **Ожидание успешного входа**:
   - Проверить появление элементов, видимых только авторизованному пользователю
   - Таймаут: 120 секунд

6. **Сохранение cookies**:
   ```python
   cookies = context.cookies()
   # Сохраняем cookies для www.ozon.ru и data.ozon.ru
   with open(COOKIES_FILE, 'w') as f:
       json.dump(cookies, f)
   browser.close()
   ```

**Важно:** cookies сохраняются в формате Playwright (с domain, path, httpOnly и т.д.)

## Шаг 4: ozon_parser.py — Парсинг одной карточки товара

**Файл:** `ozon_parser.py`

Функция `parse_product_page(page, sku)`:

### Извлечение данных из HTML:

| Поле | Источник | Метод |
|------|----------|-------|
| `sku` | URL / JSON-LD | Из URL или data-атрибута |
| `title` | HTML / JSON-LD | `<h1>`, meta `og:title`, или `window.__INITIAL_STATE__` |
| `price` | HTML / JSON-LD | `.price-wrapper .price`, meta `og:price:amount` |
| `rating` | HTML | `[class*="rating"] .value`, `aria-label` |
| `reviews_total` | HTML | `[class*="reviews"]`, count element |
| `cover_image` | HTML | `meta og:image`, или первое изображение в галерее |
| `photos_seller` | JSON / HTML | Из JSON-блока `media.photos` или счётчик в галерее |
| `videos_seller` | JSON / HTML | Из JSON-блока `media.videos` или счётчик |
| `color` | Attributes | Атрибут "Цвет" из блока характеристик |
| `material` | Attributes | Атрибут "Материал" из блока характеристик |
| `art_set` | Attributes | Атрибут "Артикул производителя" / "Комплектация" |
| `has_rich_content` | Description HTML | Поиск `<img>`, `<table>`, `<ul>/<ol>` в описании |

### Стратегия извлечения (приоритет):
1. **JSON-LD** blocks (`<script type="application/ld+json">`) — структурированные данные
2. **Embedded JSON** (`window.__INITIAL_STATE__`, `window.__DATA__`) — данные из SSR
3. **HTML selectors** — fallback через BeautifulSoup
4. **Meta tags** — og:* теги

### Rich content detection:
```python
def has_rich_content(description_html):
    soup = BeautifulSoup(description_html, 'html.parser')
    has_images = len(soup.find_all('img')) > 0
    has_tables = len(soup.find_all('table')) > 0
    has_lists = len(soup.find_all(['ul', 'ol'])) > 0
    return has_images or has_tables or has_lists
```

## Шаг 5: parse_ozon.py — Основной скрипт парсинга

**Файл:** `parse_ozon.py`

Flow:
1. Загрузить cookies из `cookies.json`
2. Загрузить список SKU из config
3. Для каждого SKU:
   - Открыть страницу через Playwright (с подменёнными headers)
   - Дождаться полной загрузки (ожидание элемента с товаром)
   - Извлечь данные через `ozon_parser.parse_product_page()`
   - Сохранить результат в список
   - Логировать прогресс
4. Записать все результаты в CSV

### Headers для подмены (anti-detect):
```python
headers = {
    'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) ...',
    'Accept': 'text/html,application/xhtml+xml,...',
    'Accept-Language': 'ru-RU,ru;q=0.9,en-US;q=0.8,en;q=0.7',
}
```

## Обработка ошибок (общая)

| Ситуация | Действие |
|----------|----------|
| Письмо не пришло за 60 сек | Retry 3 раза с задержкой 10 сек, затем лог + пропуск |
| Код не найден в письме | Лог warning, пропуск SKU |
| Страница не загрузилась (timeout) | Retry 2 раза, затем лог error, пропуск SKU |
| Элемент не найден на странице | Записать `null` в соответствующее поле |
| Playwright не установлен | Вывести понятное сообщение с инструкцией |
